# 🎮 Rock Paper Scissors Game

A modern and animated **Rock Paper Scissors** web game with sound effects, background music, score tracking, and cooldown system.  
Designed with a futuristic neon UI for a fun and engaging experience.

---

## 📖 Description

This project is a browser-based Rock Paper Scissors game where the player competes against the computer.  
Each round includes sound effects, animated feedback, and a result overlay.  
To prevent button spamming, the game includes a **cooldown timer** after every move.

---

## 🛠️ Technologies Used

- **HTML5** – structure of the game  
- **CSS3** – styling, animations, and neon effects  
- **JavaScript (Vanilla JS)** – game logic, sound handling, cooldown system  
- **Font Awesome** – icons for hand gestures and volume button  
- **Google Fonts** – Orbitron & Poppins fonts
